# Tugas Praktikum HTML Lanjutan

## Deskripsi
Tugas praktikum ini membuat halaman profil organisasi kampus menggunakan HTML. Halaman berisi informasi organisasi, gambar, hyperlink, navigasi internal, link eksternal, email, serta tiga jenis list yaitu unordered list, ordered list, dan description list.

## Fitur
- Menampilkan minimal dua gambar dengan atribut `alt`
- Menggunakan hyperlink internal dan eksternal
- Menyediakan link email menggunakan `mailto`
- Menggunakan tiga jenis list HTML
- Menggunakan atribut `id` dan `target`
- Menggunakan komentar HTML

## Tujuan
Tugas ini bertujuan untuk memahami penggunaan elemen HTML lanjutan dalam membuat halaman profil yang memiliki struktur informasi dan navigasi yang jelas.

## Teknologi
